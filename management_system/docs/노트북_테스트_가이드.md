# 노트북에서 테스트하기

## 1. 준비 (처음 한 번)
1. **Python 3.12** 설치: https://www.python.org/downloads/
   - 설치 첫 화면에서 **"Add python.exe to PATH" 체크** (중요)
2. 소스 받기 (둘 중 하나)
   - **ZIP**: GitHub 저장소 → 브랜치 `ccr-c6db4a62-vnuw8o` 선택 → `Code` → `Download ZIP` → 압축 해제
   - **Git**: `git clone -b ccr-c6db4a62-vnuw8o https://github.com/jangsworld/-.git BMS`

## 2. 실행
- **Windows**: `management_system` 폴더의 **`run_demo.bat` 더블클릭**
  - 처음에는 필요한 프로그램 설치로 1~3분 걸립니다.
  - 브라우저가 자동으로 **http://localhost:8100** 을 엽니다.
- macOS: 터미널에서 `./run_demo.sh`

검은 창(콘솔)에 아래처럼 **초기 관리자 비밀번호**가 표시됩니다. (`secrets\initial_admin_password.txt` 에도 저장됨)

```
👤 초기 관리자 계정 생성: admin / AbCd-EfGh-IjK!
```

## 3. 첫 로그인
1. 아이디 `admin`, 위 임시 비밀번호로 로그인
2. **2단계 인증 등록**: 휴대폰 Google Authenticator / Microsoft Authenticator 앱으로 QR 스캔 → 6자리 입력
3. **새 비밀번호 설정** (10자 이상, 대·소문자·숫자·특수문자 중 3종류, 'admin' 포함 불가)
4. 다른 권한도 시험하려면: 시스템 관리 → 사용자·권한 관리에서 `인사·총무담당`, `총무담당`, `조회자` 계정을 만들어 다른 브라우저(또는 시크릿 창)로 로그인

## 3-1. 입사서류 자동 등록 시험
1. `config\bms.toml` 의 `employee_root` 에 서류 폴더를 지정합니다. (Z: 대신 `\\서버\공유` 형식 권장)
2. 그 아래에 **임직원 이름으로 폴더**를 만들고 입사서류를 넣습니다. PDF·이미지·HWP·HWPX 를 읽습니다.
3. 약 1~2분 안에 임직원 현황에 **초안생성 · 확인필요** 가 나타납니다. 바로 보려면 **지금 확인** 을 누릅니다.
4. 초안을 열어 노란색 칸을 원본과 대조하고 **확인 완료 · 임직원 등록** 을 누릅니다.

- 파일명이 `통장`·`계좌` 를 포함하면 계좌번호도 읽습니다.
- 동명이인은 폴더를 `홍길동_2` 처럼 구분합니다.
- 시스템이 저장한 PDF 는 `BMS_` 로 시작하며 초안 추출에서 제외됩니다.

## 4. 자주 묻는 것
| 상황 | 방법 |
|------|------|
| 종료 | 검은 창 닫기 (또는 Ctrl+C) |
| 다시 실행 | `run_demo.bat` 다시 실행 → 입력한 데이터 그대로 유지 |
| 처음부터 다시(샘플 초기화) | 종료 후 `data\bms.db` 와 `secrets` 폴더 삭제 → 다시 실행 |
| 비밀번호 잊음 / 잠김 | `.venv\Scripts\python manage.py reset-password admin` (2FA 는 `reset-2fa admin`) |
| 2단계 인증 없이 빠르게 테스트 | `run_demo.bat` 의 `set BMS_HOST=127.0.0.1` 아래에 `set BMS_REQUIRE_2FA=false` 추가 |
| 포트 8100 사용 중 | `set BMS_PORT=8200` 추가 후 http://localhost:8200 |

> 데모 데이터는 모두 가상입니다. 실제 임직원 정보는 회사 서버 설치 후 입력하세요.
> 테스트 중에는 **이 PC에서만** 접속됩니다(외부·사내망 비공개).

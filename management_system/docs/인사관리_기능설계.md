# 경영관리업무시스템 – 인사관리 모듈 기능 설계 및 관리적 의미

## 1. 전체 구조 (경영관리시스템의 큰 틀)

```
경영관리업무시스템
├── 인사관리 (구현 완료)  ← 본 문서
├── 총무관리 (준비중): 자산·비품, 법인차량, 문서수발·관인대장, 계약·임대차, 경조사
├── 재무·회계 (준비중): 급여대장, 경비정산, 예산관리
├── 영업·입찰 (준비중): 기존 '정량적 제안서 시스템' 연동
└── 시스템: 회사정보, 기준코드(부서·직급·직책·근무지), 감사로그
```

- **임직원 마스터(employees)를 모든 모듈의 공통 기준 데이터**로 둡니다. 총무(비품 지급자·차량 운전자), 재무(급여·경비 청구자), 영업(투입 기술자)이 모두 이 마스터를 참조하도록 설계해 데이터 중복 입력을 없앱니다.
- 모듈은 `app/modules/<모듈>/` 단위로 분리되어 있고, `app/modules/__init__.py` 의 `MODULES` 에 메뉴를 추가하면 좌측 내비게이션에 자동 노출됩니다.

## 3. 향후 확장 제안 (우선순위 순)

1. **권한 관리(RBAC)·로그인** – 연봉·징계는 민감정보이므로 인사담당/팀장/본인 조회 범위 분리 (내부망 운영 전 필수 권장)
2. **근태·연차 관리** – 연차 발생/사용/촉진(근로기준법 제61조), 근로특이사항과 연동
3. **급여 연동** – 연봉현황 → 월 급여대장, 4대보험 취득·상실 신고 체크리스트
4. **인사평가·교육** – 평가등급 → 연봉 인상률 매트릭스 자동 적용(일괄 인상 시뮬레이션 확장)
5. **전자서명** – 근로계약서 서명 요청·완료를 시스템 내에서 처리
6. **조직도·정원(TO) 관리** – 부서별 정원 대비 현원, 채용 필요 인원 산출
7. **퇴직금 추계** – 근속·평균임금 기반 퇴직급여 충당부채 계산(재무 모듈 연계)

> ※ 법정 기간·한도 수치는 2026년 기준 참고값입니다. 운영 전 최신 법령·고시를 확인하고, 계약서 문구는 노무사 검토를 권장합니다.

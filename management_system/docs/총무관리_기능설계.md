# 경영관리업무시스템 – 총무관리 모듈 기능 설계 및 관리적 의미

총무 모듈은 인사 모듈의 **임직원 마스터를 그대로 참조**합니다(자산 사용자, 차량 운전자, 문서 담당자, 관인 신청자, 경조사 대상자).
그래서 퇴사 처리만 하면 "퇴사자 미반납 자산"이 자동으로 알림에 뜨는 등 두 모듈이 하나로 움직입니다.

| # | 기능 | 주요 내용 | 관리적 의미 |
|---|------|-----------|-------------|
| 0 | **총무 대시보드** | 보유 자산·장부가, 차량 수·주행거리·업무사용비율, 월 고정비(계약 환산), 문서 수발, 경조금 / 분류별 장부가, 구분별 고정비, 월별 운행·유류비, 월별 경조금 / **관리 알림** | 흩어진 만기(보험·검사·리스·라이선스·계약 통보기한)를 한곳에서 관리해 **놓치면 비용·과태료가 생기는 기한**을 예방 |
| 1 | **자산·비품** | 분류·취득연도별 **자산번호 자동부여**(IT-2026-001), 취득가·내용연수 → **정액법 월할 감가상각 장부가**, 지급·반납·이동·수리·폐기 **이력**(사용자·상태 자동 반영), AS보증·라이선스 만료, **QR 자산 라벨** 인쇄, 자산대장 CSV, 인사기록카드에 지급 자산 표시 | 실사(재물조사) 기준 자료, 퇴사 시 **회수 누락 방지**, 상각 완료 자산 파악으로 **교체 예산** 수립, 소프트웨어 라이선스 갱신 누락·불법 사용 리스크 예방 |
| 2 | **법인차량** | 차량대장(소유·리스·렌트, 월 납입액), 보험·정기검사·리스 만기, **운행일지**(출발/도착 계기판 → 주행거리 자동, 일반업무/출퇴근/비업무), 정비·보험·세금 비용, 연간 **업무사용비율**·km당 비용, **업무용승용차 운행기록부 CSV** | 법인세법상 업무용승용차 비용은 **운행기록부를 작성해야 업무사용비율만큼 인정**(미작성 시 연 1,500만원 한도). 무보험 운행·검사 지연 과태료 예방, 차량별 운영비 비교로 교체·렌트 전환 판단 |
| 3 | **문서 수발 대장** | 수신·발신 구분, **연도별 문서번호 자동 채번**(총무-2026-0001 / 수신-2026-0001), 상대기관·담당·방법·보존기간, **회신 기한** 알림 | 공문 접수·발송의 공식 기록(분쟁·감사 시 증빙), 결번·중복번호 방지, 관공서 회신 기한 준수 |
| 3-1 | **관인(인감) 사용 대장** | 법인인감·사용인감·직인별 사용 신청 → **시스템관리자 승인/반려** → 사용완료, 용도·제출처·매수 기록 | 법인인감은 대출·부동산·주요 계약에 쓰이므로 **사전 승인과 사후 추적**이 핵심 내부통제 |
| 4 | **계약·임대차** | 임대차·용역·유지보수·리스·보험 등, 금액·지급주기 → **월 고정비 환산**, 보증금, **자동갱신 여부와 해지 통보기한(만료 N일 전)**, 상태(유효/통보임박/갱신확정/만료임박/만료), 자동갱신 계약의 기간 자동 연장 | 자동갱신 계약은 **통보기한을 놓치면 원치 않게 1년 연장** → 기한 전 알림으로 비용 절감 협상 기회 확보. 월 고정비·보증금 총액으로 고정비 구조 파악 |
| 5 | **경조사** | 회사 **경조 규정**(구분·대상별 경조금·휴가·화환) 화면에서 관리, 등록 시 **규정 자동 적용**, 지급 상태·지급일, 연간 합계·구분별 집계, 비고 암호화 | 규정에 따른 **공정한 지급**과 누락 방지, 경조금 예산 관리. 경조금은 사회통념상 범위 내 비과세 |

## 권한

| 역할 | 인사 | 총무 |
|------|------|------|
| 시스템관리자 | 전체 | 전체 + **관인 사용 승인** |
| 인사·총무담당(hr) | 전체 | 전체 |
| 총무담당(ga) | 임직원 기본정보 조회만(연봉·개인정보 비공개) | 전체 |
| 조회자 | 기본정보 조회 | 현황 조회만 (경조사 비공개 — 가족 사망·질병 정보) |

## 관리 알림 규칙

| 등급 | 알림 |
|------|------|
| 🔴 | 퇴사자 미반납 자산, 소프트웨어 라이선스 만료, 차량 보험·검사 만료, 자동갱신 계약 해지 통보기한 14일 이내, 수동계약 만료, 회신기한 경과 |
| 🟠 | AS보증 만료 임박, 차량 보험·검사 30일 / 리스 90일 이내, 통보기한 임박, 계약 만료 예정, 회신기한 7일 이내 |
| 🔵 | 관인 승인 대기, 자동갱신 확정, 경조금 미지급(3일 경과) |

## 향후 확장 제안
1. **비품 신청·구매 품의** 결재 흐름 (신청 → 승인 → 구매 → 자산 자동 등록)
2. **회의실·차량 예약** 캘린더
3. **소모품 재고** (토너·용지 등 최소재고 알림)
4. 재무 모듈 연동: 계약 월 고정비·차량비 → 예산 대비 실적

BMS → 이카운트 사원등록 입력 도우미
====================================

1. run_helper.bat 을 두 번 누릅니다.
   - 처음 한 번은 구성요소(playwright)를 설치합니다. 인터넷이 필요합니다.
   - 브라우저는 PC에 있는 Microsoft Edge 를 사용합니다(따로 받지 않습니다).
2. Edge 창이 열리면 BMS 탭과 이카운트 탭에서 각각 직접 로그인합니다.
   도우미는 비밀번호를 묻거나 저장하지 않습니다.
3. 이카운트에서 사원등록 [신규] 화면(퇴사자는 그 사원의 [수정] 화면)을 엽니다.
4. 도우미 창(검은 창)에서 직원 번호를 고르고 Enter → 칸이 노란색으로 채워집니다.
   못 찾은 칸 이름이 뜨면, 이카운트에서 다른 탭(급여지급사항·기타설정)을 열고 Enter 를 누르면 이어서 채웁니다.
5. 화면을 확인하고 이카운트에서 직접 [저장] → 도우미 창에서 s 를 누르면 BMS에 반영 완료로 기록됩니다.

- d : 지금 이카운트 화면의 입력칸 목록을 파일로 저장합니다(직원 정보 없음). 칸을 못 찾을 때 이 파일을 보내 주세요.
- config.json 의 bms_url 은 BMS 주소입니다.
- 로그인 상태는 %LOCALAPPDATA%\BMS-ecount-helper\profile 에만 남습니다. 지우려면 이 폴더를 삭제하세요.
